# Agape Farmstead

Proposal decks. Edit `index.yaml`, `theme.css`, and `decks/`. The site is generated with [ProposalDecks](https://github.com/sharpninja/ProposalDecks).

```powershell
Import-Module ProposalDecks
Build-ProposalSite -Path .
```

Portrait: `docs/index.html`. Landscape: `docs/index.wide.html`.
